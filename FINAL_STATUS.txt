================================================================================
                         KEY IMPLEMENTATIONS
================================================================================

1. LLM FAILURE & EDGE-CASE HANDLING
   • Graceful degradation: Partial results if tools fail
   • Plain language: "I couldn't get X, here's what I do have"
   • Out-of-scope rejection: "I can only analyze YOUR data"
   • Tool call limits: Max 10 per investigation
   • Timeout: 30 seconds max, then degrade
   • Normal day support: "No anomaly" as valid output

2. CURRENCY ACCURACY
   • All amounts stored as paise integers (₹1 = 100 paise)
   • No floating-point rounding errors
   • Display layer formats to ₹/lakh only
   • Example: 50,000 rupees = 5,000,000 paise

3. TIMEZONE CONSISTENCY
   • IST (UTC+5:30) used throughout
   • Synthetic data generator
   • Analytics calculations
   • Frontend display
   • All ISO timestamps include +05:30

4. FINANCIAL TRANSPARENCY
   • All amounts labeled "(estimated)"
   • Confidence bounds included
   • Revenue-at-risk labeled clearly
   • Recovery probability shows uncertainty
   • Never bare numbers that could be misunderstood

5. IDEMPOTENCY GUARANTEES
   • Same action + parameters = same result
   • Prevents double-execution from retries
   • Double-click on approval button = safe
   • Deterministic key generation
   • Audit trail for verification

6. APPROVAL SAFETY
   • 30-minute approval window
   • Auto-expiration prevents stale approvals
   • Re-confirmation required if data changes
   • Clear warnings: "⚠️ CANNOT be undone"
   • Undo/cancel story for each action

7. OBSERVABILITY
   • Separate LLM debug logging
   • Metrics logging (token usage, latency)
   • Investigation ID tracking
   • Per-investigation analytics
   • Tool execution tracking
   • Error and warning counts

8. COMPREHENSIVE TESTING
   • 22 core tests (all passing)
   • 20+ robustness tests (all passing)
   • 42+ tests total
   • Edge cases covered
   • Malformed data handling
   • Load testing on 50k transactions
