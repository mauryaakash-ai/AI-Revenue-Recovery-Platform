================================================================================
                      QUICK INSTALLATION STEPS
================================================================================

STEP 1: INSTALL DOCKER
1. Download: https://desktop.docker.com/win/main/amd64/Docker%20Desktop%20Installer.exe
2. Run: Docker Desktop Installer.exe
3. Choose: "Per-user installation" and "Use WSL 2 backend"
4. RESTART YOUR COMPUTER
5. Verify: Open Command Prompt and type: docker --version

STEP 2: INSTALL NODE.JS
1. Download: https://nodejs.org/en/download/
2. Run: node-v24.18.0-x64.msi (or latest LTS)
3. Click "Next" through wizard, ensure "Add to PATH" is checked
4. RESTART YOUR TERMINAL (close and reopen Command Prompt)
5. Verify: node --version and npm --version

STEP 3: INSTALL POSTGRESQL
1. Download: https://www.postgresql.org/download/windows/
2. Run: PostgreSQL installer
3. During installation:
   - Password: postgres (REMEMBER THIS!)
   - Port: 5432 (keep default)
4. RESTART COMPUTER (important!)
5. Verify: Open Command Prompt and type: psql --version

STEP 4: VERIFY INSTALLATION
1. Open Command Prompt
2. Run: verify-installation.bat
3. Should see: [SUCCESS] All dependencies installed!

================================================================================
                      TROUBLESHOOTING
================================================================================

Docker won't start?
→ Open Docker Desktop from Start menu, wait 2-3 minutes, try again

npm: command not found?
→ Restart Command Prompt (close and reopen it)

psql: could not connect?
→ Open Services (Ctrl+R > services.msc), find postgresql, click Start

Port 5432 already in use?
→ Stop PostgreSQL service in Services, or change Docker ports

See detailed troubleshooting in:
→ WINDOWS_SETUP_GUIDE.md (Troubleshooting section)
